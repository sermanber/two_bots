Это проект телеграм-бота мероприятий. 
Бот мероприятий запрашивает информацию о готовящемся мероприятии у пользователя и отправляет собранную информацию боту-администратору. 
Оператор бота-администратора может подтвердить данное мероприятие или отклонить его.
После сбора данных от первого бота через API Telegram, данные попадают в БД. В БД настроен таргет на добавление информации. После обращения к БД новая информация попадает ко второму боту. Пользовотель второго бота подтверждает/опровергает информацию в базе данных. Информация полученная от второго бота также попадает в БД, срабатывает таргет и первый пользователь получает информацию о подтверждении/опровержении.
